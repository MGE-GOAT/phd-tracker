Mahrad Ghazli, MSc Biomedical Engineering, Sharif University of Technology (requirements completed 23 September 2026, degree certificate pending)

Research interest
I want to work on running machine learning models on constrained devices and on deciding at runtime where each model should run. The EdgeAI-Drone project asks exactly this for large language and vision-language models on a drone, an edge server and the cloud. I am applying for the pre-doc position in the Distributed Systems research division.

My thesis
My thesis is an always-on voice assistant for older adults. I designed a 75k-parameter wake-word model and trained it with int8 quantization-aware training. It takes 182 KB and runs in about 20 ms on a Raspberry Pi 4. Under five-fold cross-validation it was the most accurate of seven models on every fold. On the device's own microphone, false alarms tripled even though the offline scores barely moved. Retraining on data recorded on the device cut false activations from 60 to 3 in a 388-hour test. The whole pipeline is in C++ with TensorFlow Lite, and I verified that its features match the Python version to within one millionth. The system ran for five weeks with 53 speakers.

What this means for the project
In my system I decided by hand what runs on the device and what runs on the server. Voice commands now run on the device with a Whisper-base encoder in ONNX, and the server only relays encrypted media. I measured the cost of each choice. This project would let me study the same decision in a systematic way, with energy and bandwidth limits and changing conditions.

What I still have to learn
I have not yet optimized LLM or VLM inference. I have built production LLM agents with tool use and retrieval, and I want to learn model partitioning and runtime placement policies in this project.
